## Concepts

- **Tool Overview**: TN93 - A tool for calculating Tamura-Nei 93 genetic distance between sequences.
- **Core Function**: Computes pairwise genetic distances using the Tamura-Nei 1993 model of nucleotide substitution.
- **Input**: Aligned sequences (FASTA), sequence alignment file.
- **Output**: Distance matrix, phylogenetic tree (optional).
- **Installation**: `pip install tn93` or `conda install -c bioconda tn93`
- **Use Case**: Phylogenetic analysis, population genetics, evolutionary studies.

## Pitfalls

- **Alignment**: Requires properly aligned sequences.
- **Rate Variation**: Does not account for among-site rate variation by default.

## Examples

### Calculate distances
**Args:** `tn93 -i aligned.fasta -o distance_matrix.txt`
**Explanation:** Calculate Tamura-Nei 93 distances between sequences.

### Build tree
**Args:** `tn93 -i sequences.fasta --tree -o phylogeny.nwk`
**Explanation:** Calculate distances and build neighbor-joining tree.
