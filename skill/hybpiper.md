## Concepts

- **Tool Overview**: HybPiper is a pipeline for extracting target sequences from high-throughput sequencing reads generated by target enrichment (Hyb-Seq) methods.
- **Phylogenomic Marker Recovery**: Specifically designed for capturing hundreds to thousands of phylogenetic markers across multiple species.
- **Multi-phase Assembly**: Implements parallel execution in three phases: read mapping, contig assembly, and target sequence extraction.
- **Exon-Intron Extraction**: Automatically extracts both coding sequences (exons) and non-coding sequences (introns) for phylogenomic analysis.
- **Paralog Detection**: Identifies paralogous gene copies that may confound phylogenetic inference.
- **Installation**: `conda install -c bioconda hybpiper`

## Pitfalls

- **Reference Target File**: Requires a FASTA file of target sequences (baits) for sequence capture.
- **Read Quality**: Low-quality reads can affect assembly accuracy; preprocess reads before running HybPiper.
- **Computational Resources**: Assembly of multiple loci across many samples can be computationally intensive.
- **Paralog Handling**: Paralogs need careful inspection and filtering before downstream phylogenetic analysis.
- **Memory Requirements**: Assembling large datasets requires sufficient memory for parallel processing.
- **Output Interpretation**: Multiple output files require careful interpretation for downstream analysis.

## Examples

### Run HybPiper on a single sample
**Args:** `hybpiper assemble -t_baits targets.fasta -r sample_R1.fastq.gz sample_R2.fastq.gz --prefix sample1`
**Explanation:** Runs the full assembly pipeline on paired-end reads for a single sample.

### Run across multiple samples
**Args:** `hybpiper assemble -t_baits targets.fasta --samples samples.txt --output_dir results/`
**Explanation:** Processes multiple samples listed in a text file.

### Extract sequences for phylogenetics
**Args:** `hybpiper retrieve_sequences -t_baits targets.fasta -d results/ --fasta`
**Explanation:** Retrieves assembled sequences in FASTA format for phylogenetic analysis.

### Check paralogs
**Args:** `hybpiper paralog_check -d results/`
**Explanation:** Identifies potential paralogous sequences in the assembled data.

### Generate summary statistics
**Args:** `hybpiper stats -d results/ -o stats_summary.txt`
**Explanation:** Generates summary statistics for the assembled loci.
