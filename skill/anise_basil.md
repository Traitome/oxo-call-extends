## Concepts

- **Tool Overview**: anise_basil (v1.2.0) consists of two complementary tools: BASIL for breakpoint detection and ANISE for insertion assembly from high-throughput sequencing data.
- **BASIL Function**: Detects breakpoints for structural variants (including insertion breakpoints) from aligned paired HTS reads in BAM format using OEA (one-end anchored) alignments.
- **ANISE Function**: Assembles large insertions from paired reads in BAM format using candidate insert breakpoints generated by BASIL.
- **Two-Step Workflow**: First run BASIL to identify tentative insertion sites, then run ANISE to assemble the inserted sequences.
- **Repeat Resolution**: ANISE employs a repeat resolution step for near-identity repeats that are challenging for traditional assemblers.
- **Output Formats**: BASIL outputs VCF with breakpoint calls; ANISE outputs FASTA with assembled insertion sequences.
- **Installation**: Available via Bioconda (`conda install -c bioconda anise_basil`) or from source via GitHub.

## Pitfalls

- **Version Differences**: Options may vary between versions.
- **Input Format**: Requires properly aligned BAM files with indexed references.
- **OEA Reads**: Detection relies on one-end anchored reads; low coverage may miss breakpoints.
- **Filtering Required**: BASIL output requires filtering (e.g., by OEA count) before ANISE assembly.
- **Reference Bias**: Highly similar reference sequences may affect breakpoint detection accuracy.
- **Computational Resources**: Large datasets require sufficient memory for processing.

## Examples

### Display BASIL help
**Args:** `basil -h`
**Explanation:** Shows available options for BASIL breakpoint detection.

### Display ANISE help
**Args:** `anise -h`
**Explanation:** Shows available options for ANISE insertion assembly.

### Basic BASIL breakpoint detection
**Args:** `basil -ir ref.fa -im aligned.bam -ov basil.vcf`
**Explanation:** Detects structural variant breakpoints from aligned BAM file. Outputs VCF with insertion site predictions. Requires indexed reference genome.

### Filter BASIL output
**Args:** `filter_basil.py -i basil.vcf -o basil.filtered.vcf --min-oea-each-side 10`
**Explanation:** Filters BASIL VCF to retain only high-confidence breakpoints with at least 10 OEA reads on each side. Recommended before ANISE assembly.

### ANISE insertion assembly
**Args:** `anise -ir ref.fa -im aligned.bam -iv basil.filtered.vcf -of anise.fa`
**Explanation:** Assembles insertion sequences using filtered BASIL breakpoints. Outputs FASTA with assembled contigs anchored to reference positions.

### Extract spanning contigs
**Args:** `extract_spanning anise.fa > anise.filtered.fa`
**Explanation:** Extracts only "spanning" contigs from ANISE output - those that fully span the insertion with both ends anchored.

### Complete workflow
**Args:** `basil -ir ref.fa -im reads.bam -ov basil.vcf && filter_basil.py -i basil.vcf -o basil.filtered.vcf --min-oea-each-side 5 && anise -ir ref.fa -im reads.bam -iv basil.filtered.vcf -of insertions.fa`
**Explanation:** Full pipeline: detect breakpoints → filter → assemble insertions. Standard workflow for structural variant analysis.

### BASIL with verbose output
**Args:** `basil -ir ref.fa -im aligned.bam -ov basil.vcf -v`
**Explanation:** Enables verbose mode for debugging breakpoint detection issues.
