## Concepts

- **Tool Overview**: mapdamage2 v2.2.3 - mapDamage tracks and quantifies damage patterns in ancient DNA sequencing reads generated by Next-Generation Sequencing platforms.
- **Core Function**: Analyzes and quantifies DNA damage patterns in ancient DNA sequencing data.
- **Input/Output**: Input: BAM alignment file, reference genome; Output: Damage plots, statistics.
- **Installation**: `conda install -c bioconda mapdamage2`
- **Damage Patterns**: Detects characteristic ancient DNA damage patterns (e.g., C->T, G->A transitions).
- **Quality Assessment**: Provides quality assessment metrics for ancient DNA samples.

## Pitfalls

- **Alignment Quality**: Poor quality alignments affect damage estimation.
- **Modern Contamination**: Modern DNA contamination masks true damage patterns.
- **Read Length**: Short reads may not provide enough information for damage analysis.
- **Reference Genome**: Must use the same reference used for mapping.
- **Coverage**: Low coverage regions may produce unreliable results.
- **Post-mortem Damage**: Different types of post-mortem damage require different analysis approaches.

## Examples

### Run damage analysis
**Args:** `mapdamage2 -i aligned.bam -r ref.fa -o damage_results/`
**Explanation:** Analyzes damage patterns in aligned BAM file.

### With quality filtering
**Args:** `mapdamage2 -i aligned.bam -r ref.fa -o damage_results/ -q 30`
**Explanation:** Filters reads with mapping quality < 30.

### Quick mode
**Args:** `mapdamage2 -i aligned.bam -r ref.fa -o damage_results/ --quick`
**Explanation:** Runs in quick mode for faster analysis.

### Verbose mode
**Args:** `mapdamage2 -i aligned.bam -r ref.fa -o damage_results/ -v`
**Explanation:** Provides detailed logging during analysis.

### Generate plots only
**Args:** `mapdamage2 -i aligned.bam -r ref.fa -o damage_results/ --plots-only`
**Explanation:** Generates only damage plots without statistics.

### Custom bin size
**Args:** `mapdamage2 -i aligned.bam -r ref.fa -o damage_results/ -b 100`
**Explanation:** Sets custom bin size for analysis.
