## Concepts

- **Tool Overview**: BANNER (v0.0.2) is a tool that interprets and visualizes HULK histosketches, helping make sense of genomic sequence similarity data.
- **Core Function**: Analyzes and visualizes histosketches generated by HULK for sequence comparison.
- **Histosketch Analysis**: Processes HULK histosketch data to extract sequence similarity information.
- **Visualization**: Generates visual representations of histosketch comparisons.
- **Similarity Detection**: Identifies sequence similarities between samples using sketch-based methods.
- **Input/Output**: Accepts HULK histosketch files; outputs analysis reports and visualizations.
- **Installation**: `conda install -c bioconda banner`.

## Pitfalls

- **HULK Dependency**: Requires HULK-generated histosketch files as input.
- **Sketch Compatibility**: Only compatible with HULK histosketch format.
- **Large Datasets**: May require significant memory for large-scale comparisons.
- **Version Differences**: Options may vary between versions. Check help for your version.

## Examples

### Analyze histosketch
**Args:** `banner analyze -i sketch.hulk -o report.txt`
**Explanation:** Analyzes HULK histosketch and generates report.

### Visualize comparison
**Args:** `banner plot -i sketch1.hulk sketch2.hulk -o comparison.png`
**Explanation:** Creates visualization comparing two histosketches.

### Batch processing
**Args:** `banner batch -i sketches.txt -o results/`
**Explanation:** Processes multiple histosketch files in batch mode.

### Export metrics
**Args:** `banner metrics -i sketch.hulk -o metrics.json`
**Explanation:** Exports similarity metrics in JSON format.

### Compare multiple samples
**Args:** `banner compare -i sample1.hulk sample2.hulk sample3.hulk -o matrix.txt`
**Explanation:** Generates similarity matrix between multiple samples.

### Generate heatmap
**Args:** `banner heatmap -i sketch_dir/ -o heatmap.png`
**Explanation:** Creates heatmap visualization of sample similarities.

### Display help
**Args:** `banner --help`
**Explanation:** Shows all available command-line options and usage information.
