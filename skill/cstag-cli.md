## Concepts

- **Tool Overview**: cstag-cli (v1.0.0+) is a command-line interface for manipulating minimap2's CS (cigar string) tag in SAM/BAM alignment files.
- **Core Function**: Provides utilities for parsing, filtering, and transforming CS tags to extract detailed alignment information.
- **Input/Output**: Input: SAM/BAM files with CS tags from minimap2. Output: Modified SAM/BAM files or text reports.
- **CS Tag**: The CS tag in minimap2 contains base-level alignment information showing matches, mismatches, and gaps.
- **Key Features**: Extract variants from alignments, filter alignments by CS tag content, convert CS tags to VCF format.
- **Installation**: `conda install -c bioconda cstag-cli`

## Pitfalls

- **CS Tag Requirement**: Input BAM/SAM must contain CS tags (generated by minimap2 with `--cs` flag).
- **Index Requirement**: BAM files must be indexed for efficient random access; use `samtools index` first.
- **Memory Usage**: Processing large BAM files may require significant memory; consider streaming or splitting.
- **Output Format**: Ensure correct output format is specified for downstream tools.
- **Version Compatibility**: CS tag format may vary between minimap2 versions; check compatibility.

## Examples

### Extract variants from BAM
**Args:** `cstag-cli variants -i alignments.bam -o variants.vcf`
**Explanation:** Extract variant calls from CS tags and output in VCF format.

### Filter alignments by identity
**Args:** `cstag-cli filter -i alignments.bam -o filtered.bam --min-identity 95`
**Explanation:** Filter alignments to retain only those with ≥95% sequence identity based on CS tag.

### Convert CS tags to text
**Args:** `cstag-cli view -i alignments.bam -o cs_tags.txt`
**Explanation:** Extract and display CS tag information in human-readable text format.
