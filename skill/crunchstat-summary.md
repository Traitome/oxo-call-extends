## Concepts

- **Tool Overview**: crunchstat-summary (v3.2.1+) - Arvados component that reads crunch log files and summarizes resource usage for workflow executions.
- **Core Function**: Parses log files generated by Arvados workflow execution, extracting CPU time, memory usage, disk I/O, and execution times for analysis and reporting.
- **Input**: Arvados crunch log files (typically in /var/lib/arvados crunch-logs directory).
- **Output**: Summary tables/reports of resource utilization by task, workflow, or time period.
- **Application**: Workflow optimization, resource allocation planning, cost analysis for cloud/HPC execution.
- **Installation**: Part of Arvados distribution; typically installed via Arvados package or Docker container.

## Pitfalls

- **Log File Location**: Default log locations may vary by Arvados installation; check configuration.
- **Permission Issues**: Read access to log files may require appropriate permissions.
- **Log Format Changes**: Different Arvados versions may have different log formats; ensure compatibility.

## Examples

### Summarize all logs in directory
**Args:** `crunchstat-summary /var/lib/arvados/crunch-logs/`
**Explanation:** Process all crunch log files in the specified directory and output resource usage summary.

### Summarize specific workflow logs
**Args:** `crunchstat-summary /var/lib/arvados/crunch-logs/workflow-xxxxx/`
**Explanation:** Generate resource usage report for a specific workflow execution.

### Output in JSON format
**Args:** `crunchstat-summary /var/lib/arvados/crunch-logs/ --format json -o usage.json`
**Explanation:** Export resource usage data in JSON format for programmatic processing.

### Summarize by task
**Args:** `crunchstat-summary /var/lib/arvados/crunch-logs/ --group-by task`
**Explanation:** Group resource usage statistics by individual task rather than overall summary.

### Filter by time range
**Args:** `crunchstat-summary /var/lib/arvados/crunch-logs/ --start 2024-01-01 --end 2024-01-31`
**Explanation:** Include only logs from specified date range for focused analysis.
