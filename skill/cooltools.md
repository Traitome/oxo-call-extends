## Concepts

- **Tool Overview**: Cooltools provides a suite of command-line tools for analyzing Hi-C and other genomic interaction data stored in .cool format, enabling comprehensive 3D genome analysis.
- **Core Function**: Computes key Hi-C features including insulation scores, eigenvectors (A/B compartments), expected contact frequencies, saddle plots, and loop calling.
- **Algorithm**: Implements various statistical methods for Hi-C analysis including matrix balancing, eigenvector decomposition, and peak calling.
- **Input**: .cool or .mcool files generated by cooler, chromosome sizes file.
- **Output**: Analysis results in TSV, NPZ, or image formats.
- **Application**: 3D genome analysis, TAD boundary detection, compartment analysis, and loop calling.
- **Installation**: Install via bioconda: `conda install -c bioconda cooltools`

## Pitfalls

- **Balanced Data Required**: Most analyses require balanced (normalized) cool files; run `cooler balance` first.
- **Resolution Selection**: Different analyses work best at different resolutions (TADs at 10kb, compartments at 100kb).
- **Memory Usage**: Whole-genome analyses at fine resolution can be memory-intensive; use region-based queries.
- **Expected Contacts**: Computing expected contacts is a prerequisite for many other analyses.
- **Chromosome Naming**: Ensure consistent chromosome naming between input files.

## Examples

### Compute insulation score for TAD boundaries
**Args:** `cooltools insulation -r 10000 input.mcool::resolutions/10000 -o insulation.tsv`
**Explanation:** Computes insulation score at 10kb resolution to identify TAD boundaries.

### Compute eigenvectors for compartments
**Args:** `cooltools eigs-cis -r 100000 input.mcool::resolutions/100000 -o eigs.npz`
**Explanation:** Computes first eigenvectors (A/B compartment signal) at 100kb resolution.

### Call dots (loop calls)
**Args:** `cooltools dots -r 10000 input.mcool::resolutions/10000 -p 4 -o dots.tsv`
**Explanation:** Identifies significant looping interactions using 4 threads.

### Generate saddle plot
**Args:** `cooltools saddle -r 100000 input.mcool::resolutions/100000 eigs.npz -o saddle.npz`
**Explanation:** Generates saddle plot data using pre-computed eigenvectors.

### Compute pile-up at features
**Args:** `cooltools pileup -r 10000 input.mcool::resolutions/10000 features.bed -o pileup.npz`
**Explanation:** Computes average contact profile around specified genomic features.

### Display help
**Args:** `cooltools --help`
**Explanation:** Shows all available commands and usage information.
