## Concepts

- **Tool Overview**: N50 v1.9.3 is a command-line tool for calculating N50 and comprehensive assembly statistics from FASTA or FASTQ sequence files. It provides quick quality assessment of genome assemblies.
- **Core Function**: Calculates N50 (the contig length at which 50% of the assembly is contained in contigs of at least that length) along with other assembly metrics like N90, L50, and total assembly length.
- **Assembly Metrics**: Computes multiple contig statistics including: N50, N90, N75, L50 (number of contigs at N50), L90, total bases, number of contigs, and longest/shortest contig.
- **Input Format**: Accepts FASTA and FASTQ files (gzipped or uncompressed) containing assembled contigs or reads. Can process multiple files for comparison.
- **Output**: Reports assembly statistics in tabular format to stdout, with option to output detailed JSON format for programmatic processing.
- **Use Case**: Assembly quality control, comparing assembly methods, evaluating different assemblers, and rapid preliminary assessment of assembly quality.

## Pitfalls

- **Assembly vs Reads**: N50 is meaningful for assemblies, not raw reads. Applying to FASTQ reads gives misleading results.
- **Contig Filtering**: Filtering very short contigs before calculation significantly affects N50. Always report filtering criteria.
- **Version Differences**: Different N50 calculators may give slightly different results due to algorithmic variations. Be consistent with tool choice.
- **Multiple Assemblies**: When comparing, run all assemblies through the same tool with identical parameters.
- **Reference Comparison**: N50 alone doesn't indicate assembly correctness. A high N50 could still be incorrect.
- **File Format**: File format detection should be automatic but may fail on unusual file extensions. Explicitly specify format if needed.

## Examples

### Basic N50 calculation
**Args:** `n50 assembly.fasta`
**Explanation:** Standard N50 calculation. Outputs N50, N90, L50, total length, and contig count.

### Detailed JSON output
**Args:** `n50 assembly.fasta -j`
**Explanation:** Outputs detailed assembly statistics in JSON format for programmatic parsing.

### Compare multiple assemblies
**Args:** `n50 assembly1.fasta assembly2.fasta assembly3.fasta`
**Explanation:** Calculates and compares N50 statistics across multiple assemblies side by side.

### Set minimum contig length
**Args:** `n50 assembly.fasta -m 500`
**Explanation:** Filters out contigs shorter than 500bp before calculating statistics. Always report this threshold.

### Display all statistics
**Args:** `n50 assembly.fasta -a`
**Explanation:** Shows all available statistics including N50, N75, N90, L50, L75, L90, total bases, etc.

### Display help
**Args:** `--help`
**Explanation:** Shows all available options and statistics that can be calculated.
